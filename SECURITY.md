# Política de segurança

Se você encontrar uma vulnerabilidade neste plugin ou no gateway Salesimpact Data, **não abra issue pública**.
Envie os detalhes por e-mail para o responsável de segurança da Salesimpact (contato oficial em https://salesimpact.com)
ou use o relato privado de vulnerabilidades do GitHub (Security > Report a vulnerability), se habilitado.

Nunca envie chaves, tokens ou dados pessoais reais no relato.
